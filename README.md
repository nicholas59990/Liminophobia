# Liminophobia: The Forgotten Space
 
> *Survive the unknown. Find your way out.*
 
A Backrooms-inspired 3D survival horror game built in Unity. You wake up in a mysterious realm with no memory of how you got there. Explore liminal spaces, solve puzzles, and avoid the entities that lurk in the dark. There is no combat, only stealth and tension.
 
**Authors:** Nicholas Marijon & Daniel Perrotta
 
The full Game Design Document lives on the `documents` branch.
 
---
 
## Getting Started
 
### Requirements
 
- Unity (version: 6000.5.7f1)
- Git
### Running the project
 
1. Clone the repo:
```
   git clone https://github.com/nicholas59990/Liminophobia.git
```
2. Open Unity Hub, click **Add → Add project from disk**, and select the `Limno_Myst` folder.
3. Open the project and load the starting scene.
4. Press **Play**.
> The first open may take a while, since Unity regenerates the `Library` folder (which is intentionally not tracked by Git).
